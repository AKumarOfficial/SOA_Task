1. What is Git?
Git is a version control tool that helps us keep track of changes made to files and projects. It is widely used in software development to manage code and collaborate with others.

2. Why Git is useful?
Git makes it easy to save different versions of a project and go back if something goes wrong. It also allows multiple people to work on the same project without overwriting each other's work.

3. Difference between Git and GitHub?
Git is a tool used on a computer to track changes in files.
GitHub is an online platform where Git repositories can be stored and shared with others.
